Privacy first

If you loved VS Code or Antigravity, this feels like home.

Undisclosed is an editor-first product built on Eclipse Theia (not a repackaged VS Code), with an agent that treats your workspace as the canvas. Familiar keybindings, your extensions, the terminal you already use, and an agent panel that is a native part of the editor instead of a side window.

Under the hood, the agent capability comes from Eigent AI; the editor shell and on-device packaging are our own, fused into a single editor-first product.

  • Agent-native editor shell, 100% open source (Apache-2.0)
  • Import your VS Code settings and extensions
  • Monaco editor, git, debugging, search, terminal

What makes it different

A serious agent, running where your code already lives.

Nothing is sent to a vendor cloud. You choose the models. The editor and the agent both run on your machine.

Privacy first

Local by default. Your code, the editor, and the agent brain all run on-device. No SaaS runtime, no vendor cloud, no telemetry you didn't ask for.

Local models & BYOK

Run a local model on your own hardware, or bring your own keys for cloud models you trust. You decide what runs, and where.

All conversations are local

Chats, memory and context are stored on your disk. Your prompts and your code don't get shipped off to a third party to be kept.

Agent inside the editor

The agent panel is a first-class dock widget, the Antigravity model. It plans in your editor and executes changes you can see and review, not in a separate window.

It can touch your workspace

Terminal, file read/write, git, search, debugging, browser and screenshots, via selectable "hands". The agent does real work against your real files.

notify

Know when it needs you

We notify you the moment the agent finishes its work or needs your input, so you can step away and get pulled back only when it matters.

Models

Any model. Your keys. Your machine.

Point Undisclosed at a local model server or connect a provider with your own key. Nothing is proxied through us.
