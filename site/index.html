Privacy first

Local by default. Your code, the editor and the agent brain all run on-device. No SaaS runtime, no vendor cloud, no telemetry you did not ask for.

Run a model on your own hardware, or bring keys for cloud models you trust. You decide what runs, and where.

Conversations stay local

Chats, memory and context are stored on your disk, not shipped off to be kept.

If you loved VS Code or Antigravity, this feels like home.

Undisclosed is an editor-first product built on Eclipse Theia, not a repackaged VS Code, with an agent that treats your workspace as the canvas. Familiar keybindings, your extensions, the terminal you already use.

The agent capability comes from Eigent AI; the editor shell and on-device packaging are our own, fused into a single editor-first product.

  • Agent-native editor shell, 100% open source under Apache-2.0
  • Import your VS Code settings and extensions
  • Monaco editor, git, debugging, search and terminal, included
