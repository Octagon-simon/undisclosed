03 / What is inside

A coding editor first. The agent is part of it.

Undisclosed is Eclipse Theia with an agent docked into the editor, not a chat window parked next to one. Same terminal, same git, same keys.

04 / Skills

A skill is a folder the agent reads when it needs it.

No plugin runtime and no marketplace account. A folder with a SKILL.md frontmatter block and instructions. The agent loads the ones that match the task, so a long list never becomes a long prompt.

05 / Where it runs

Local is the default. Cloud is a choice you make per model.

Two processes, both yours: the editor on :3000 and the brain on :5001, talking over localhost. Nothing passes through an Undisclosed server.

01The editor

Your files, your extensions, your terminal. Theia and Electron on this machine.

02The brain

FastAPI on localhost. History, memory and project state on disk under ~/.undisclosed.

03The model

A local model keeps the whole loop offline. A cloud key sends the request to that provider, and nothing else.

No fine print: there is no Undisclosed account and no analytics SDK in the app. If you choose a cloud model, your prompt and the context the agent sends go to that provider. That is what BYOK means, and the editor and brain still run here.

Straight answers

Do I need an API key?

No. Run a model locally through Ollama, LM Studio or Hugging Face and the agent works without a key. Cloud models are optional: add a key in Models and pick the model per task.

Is my code sent anywhere?

With a local model, no. With a cloud model, the prompt and the context the agent sends go to that provider. There is no Undisclosed server in between, and no account to attach it to.

Does it work offline?

The editor and the brain run offline. The agent needs a model, so a local model is what makes the full loop work with the network off.

Can I keep my VS Code setup?

Settings, themes and extensions import from VS Code and Open VSX. Extensions that only exist in the Microsoft marketplace are not on Open VSX, and the import summary tells you which ones were skipped.

What does it cost?

The app is Apache-2.0 and free to build and run. If you use a cloud model, you pay that provider directly for the tokens you use.

Is the download signed?

Not yet. Builds are unsigned for now. On macOS, right-click the app and choose Open the first time. Windows and Linux builds are on the releases page.
